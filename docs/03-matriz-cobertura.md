# 03 · Matriz de cobertura (v0.1)

> Formato do escopo §6 ("Delimitação antes do orçamento"): operação, dados exigidos, regras, comportamento em exceção e responsável pela validação.
>
> **Responsável pela validação** de todas as linhas: os responsáveis tributários (os dois stakeholders, D3). Nenhuma linha está validada nesta versão. Os comportamentos propostos para operações fora do recorte são **propostas** e precisam de aprovação.
>
> Legenda do status: `covered` (atendido), `partially_covered` (atendido parcialmente: calcula a parte coberta e sinaliza o resto), `specialist_review_required` (revisão especializada necessária: bloqueia a conclusão automática).
>
> Regra geral: o diagnóstico roda **antes** do cálculo, e o status final é o mais restritivo entre as operações encontradas (`mostRestrictiveCoverage`). Dados obrigatórios `Missing` não mudam a cobertura, mas **impedem a conclusão definitiva** (critério de aceite 3).
